# CGE · Le vrai du faux — trainer BTS SIO (session 2027)

**🔗 En ligne :** https://neroclaw.github.io/cge-trainer/ · **📦 Code :** https://github.com/NeroClaw/cge-trainer

Trainer interactif pour l'épreuve de **Culture générale et expression** du BTS, thème 2027 « Le vrai du faux ».

## Ce que couvre le site

- **Format réel** de l'épreuve depuis la session 2025 (arrêté du 13 juillet 2023) : 3 h, coef 3, questions sur le corpus /10 + essai /10. La synthèse de documents n'existe plus.
- **Méthode des questions sur corpus** : 6 recettes (annoter, décoder les verbes de consigne, relevé analysé, confrontation, calibrage, réponse modèle entièrement rédigée).
- **Méthode de l'essai** : choix du sujet en 2 minutes, structure, triade d'exemples, 3 plans-types, conclusion qui tranche, introduction modèle.
- **Le thème en 3 axes** : le faux qui trompe, le faux qui révèle, le faux qui se vend + 12 citations exploitées et 6 faits datés.
- **Entraînement** : chronomètre 3 h calé sur les 4 phases officielles, checklist de relecture, quiz de rappel actif sur chaque chapitre.
- **Mode Focus** (par défaut) : une seule unité à l'écran, navigation ← → et swipe, progression sauvegardée localement.

## Stack

Site statique : `index.html` + `content.js` (contenu) + `app.js` (rendu, focus, quiz, chrono). Aucune dépendance de build, aucune requête serveur.
